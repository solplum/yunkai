# 云开 Android 使用说明

## 安装与设备

- 应用名称：云开 / Yunkai；独立包名 `com.zhuolin.yunkai.next`，不会覆盖旧云开或 Mika 的私有数据。
- 手机后台操控需要 Android 13 及以上，推荐 Android 14 及以上的独立显示焦点支持。安装要求与操控要求不同，不能因能安装就判断可控机。
- Linux 文件计算环境仅支持 arm64；其他架构不应宣称支持该功能。不同厂商的后台、输入和无障碍行为仍须按设备验证。
- 从本次交付的 APK 安装，不从 Mika 的上游更新入口升级本应用。本应用不自动检查上游 APK。
- 测试过的具体设备、APK 哈希、通过与未通过的范围，以随附验收报告为准；本指南不是测试通过声明。

## 首次设置

1. 在模型设置中填写自己的服务地址、API Key 和模型。主模型需要支持工具调用；按界面测试结果选择，不以名称猜测能力。
2. 需要看图时显式选择支持图像的模型。旧云开的长文模型设置不等于视觉能力，不能自动代替。
3. 按应用内手机操作向导，在自己的设备上决定是否启用开发者选项、无线调试、配对和无障碍。不要把调试端口暴露到公网，也不要把配对码交给陌生人。
4. 通知权限用于提示接管、问题和结果。无需为了聊天而先授予全部手机操控权限。
5. 先用测试内容做低风险任务：打开应用找到内容、填写但不发送的草稿、返回核对。确认正确后再使用重要场景。

系统授权必须由设备主人决定。提供安装包或在云端通过测试，不等于已经获得你真实手机的调试、账号或数据访问授权。

## 怎么交代任务

说明目标、目标应用和完成条件。例如：

- “打开设置，找到蓝牙页面，告诉我当前状态，不要修改。”
- “在测试笔记应用创建一份标题为‘示例’的草稿，填写后回到详情页核对，不要分享。”
- “找到指定内容并总结；如果有同名项，先让我确认，不要猜。”

后台屏运行的是本机安装的应用，不是另一台手机。同一个应用正在主屏被你使用时，不能承诺前后台完全独立同时操作。密码、受保护窗口、登录和其他需要接管的页面，以实际提示处理。

## 确认与停止

- 默认询问模式：付款/下单、已识别的不可逆操作和未知风险需要确认；普通浏览、填写以及任务内的常规外发操作并非每一步都问。
- 删除等不花钱的动作不需要编造金额。确认只针对当次匹配对象；过期、拒绝、对象变化或不明确时不能继续套用。
- 默认询问模式中，付款本身通过接管交给本人处理；需要密码等人工步骤时按实际提示接管。
- 自主模式会跳过审批，包括付款审批，是不同的授权选择，不能把它当作更快的普通模式随意开启，也不能假定该模式下付款会被自动阻断。请先阅读界面说明。
- 停止无法撤回已经发生的外部效果。结果不确定时先核对，尤其不要反复点击发送或删除。

风险分类依赖可观察界面和规则，不是形式化安全保证。重要操作仍应核对对象与结果。

## 云开的技能、记忆与数据

- 内置“讲解 / eli5”和“狗头军师”已接入技能目录及真实读取流程。可以描述需求，或使用相应中文名称和 `@eli5` / `@狗头军师` 提示。
- 讲解默认使用应用可显示的 Markdown；需要离线 HTML 文件时通过文件输出流程交付，不把整页 HTML 塞进普通气泡冒充渲染。
- 本版使用新底座的本地记忆与技能系统。旧云开的历史、个人技能、模型凭据和隐私配置**不会自动迁移**；旧应用的数据仍留在旧应用中。不要假定旧黑名单或确认档位已经继承。
- 本地保存不等于离线推理。问题、必要历史、屏幕内容、图像和相关记忆可能随请求发送给你选择的模型服务；搜索和网站访问也有各自的目的地。
- 不要在问题、截图或反馈日志中附 API Key、密码、验证码或真实敏感资料。诊断信息发送前仍应查看内容。

## 获取结果与排障

- 文件导出位置为 `Download/Yunkai`；文件卡片中的实际名称以系统分配的名称为准。
- 找不到目标时不要让它盲目重试旧坐标。重新观察，说明当前页面和具体目标。
- 应用、系统更新或焦点被其他窗口抢走后，原操作路线可能失效；重新确认当前页面。
- 模型连接、手机助手和无障碍状态分别检查，不能用“模型能聊天”证明手机助手已连接。
- 关于页保留本地诊断预览/复制和上游归属信息；不会替你给原作者发送消息或导向上游 APK 更新。
